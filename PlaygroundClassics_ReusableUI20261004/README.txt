Playground Classics — reusable UI templates

Drag Playground-UI-Templates.svg into Figma. It is the only SVG in this pack.
The PNG is a preview, not another import sheet.

There are eleven named template groups:
Button, Panel Shell, Round Header, Meter, Player Card, Info Card, Item Card,
Status Text, Icon Palette, Status Badge and Scrollbar.

Coverage was checked against the five current ScreenGuis: British Bulldog,
Tag, Stuck in the Mud, the lobby/shop/voting shell and the admin panel
(327 GuiObjects). These are reusable visual families; full screens combine
them. Container frames, spacing and the plain dim backdrop need no separate
artwork. This sheet is not 327 separate designs.

Edit one design for each group. The Button supplies Sprint, Dodge, Vault,
Shop, Admin, Buy/Use, start/stop and voting/category actions. Their labels and
colors change when reused; they do not need separate exported designs.
The Item Card supplies all 12 shop slots. The Meter supplies stamina, XP,
heat and rescue progress. The same Round Header supplies all three games.
The Panel Shell supplies shop, admin, voting, results and world signs.
Countdown numbers and other repeated text reuse Status Text.
The Status Badge supplies role, tagged/frozen, departure and boost notices.
Its support line and count are optional. The Scrollbar supplies the shop,
admin and results lists; rotate it for vertical lists.

The Round Header includes separate team counts, captions, timer and phase.
The Player Card includes avatar, level, XP label and XP track. The Item Card
has Action and Try placement guides: put instances of the shared Button in
those positions. The Button has optional icon and keyboard-hint slots.
Dashed boxes are placement guides. Remove a guide when placing its content.
Each template can be resized for its screen; Sprint, Shop and Buy still
share one button design.

Do not duplicate the sheet for each game or state. Send the edited sheet
back and the same templates can be applied across the existing UI.
TemplateReuseMap.json records the reusable families.

Labels are separate SVG text nodes with Luckiest Guy and Fredoka One font
names. The fonts are not bundled. SVG source text remains editable. If your
Figma import outlines a label, replace that placeholder with a Figma Text
layer once in the master, then reuse the master. The illustration and
preview slots are editable vectors; they are placeholders for runtime icons,
avatar views and 3D shop models.

This package is a design export. Roblox Studio and your existing Figma canvas
were not changed. No separate numbered tiles were added: numbers were an
example of reuse, not another family of assets.

Local source, rendering and validation scripts remain in the Source folder.
The download ZIP contains only the SVG, preview, reuse map and this note.
