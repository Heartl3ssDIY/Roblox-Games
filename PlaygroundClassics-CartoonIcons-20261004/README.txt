PLAYGROUND CLASSICS - CARTOON UI ICONS

Five separate reusable PNG images: heart, level-star, dodge-swoosh,
sprint-lightning and cash-coin. No SVGs.

256px/ contains the 256x256 exports.
512px/ contains the 512x512 exports.
Originals/ contains the full-resolution generated PNGs.
All icon files have genuine transparent backgrounds. Preview.png uses a grey
presentation background only, and is not an individual icon asset.

Use these as separate image layers above your button or panel background.
Keep a square image container or use ScaleType=Fit to preserve proportions.
No captions, backplates or numbers are baked into these icons. The cash coin
has a dollar symbol; the level star is a separate five-point star.

Created with the built-in image-generation tool, one generation per icon.
Prompt direction: one centred raster UI icon, genuine transparent background,
thick dark navy outline, chunky simple silhouette, saturated colours, broad
cel shading, ivory shine, darker bevel edge, readable at small sizes.
Subjects: coral red heart; gold five-point level star; cyan-blue curved dodge
arrow with motion streaks; gold sprint lightning; single gold dollar coin.
The finished artwork was resized without changing its design.
