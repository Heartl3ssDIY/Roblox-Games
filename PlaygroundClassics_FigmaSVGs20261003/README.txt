Playground Classics - editable UI SVGs
Exported 3 October 2026 from the authored Playground Classics UI in Roblox Studio.

Unzip the package, then drag UI-Kit-Overview.svg into a Figma Design canvas for one board of the main UI pieces. For complete screen layouts, drag files from Screens. For individual parts, use Panels, Controls, ShopItems, Templates, Icons and WorldUI. PNG files are previews only.

The package contains 219 SVGs:
- 35 full screen examples for British Bulldog, Tag You're It, Stuck in the Mud and the lobby.
- 24 additional state fragments for sprinting, results, voting, levels, shop actions and other states.
- Every authored panel and control, both desktop and compact variants.
- All 12 shop item cards plus the editable item-card template.
- 20 world/overhead artworks: 18 designs covering all 30 authored world GUI instances, and the star/heart emoji variants.
- One overview board with 30 main panels.

All 327 authored GuiObjects from the five ScreenGuis are represented. Hidden widgets are exported into separate visible files. Named groups, paths, rounded shapes, strokes, gradients and SVG text remain editable; there are no embedded PNG/JPEG screenshots or external image references.

Use Luckiest Guy and Fredoka One for the game UI, and Arimo for the emoji/fallback text. The font names are retained in the SVGs. Fonts are not bundled. Source measurements used the actual installed Roblox TTFs.

The SVG source retains text as text. If you want labels to become native editable Figma Text layers rather than vector lettering, use the optional FigmaTextImporter helper. Its README explains local development installation and file import. It uses only chosen local files and has no network access. It runs only when you click Import; it was not installed or run in your Figma account. Syntax and mocked checks passed, including clipping and countdown rotation; actual Figma font metrics and placement have not been checked in a live Figma file.

The original 3D ViewportFrame content is represented as editable vector projections of its primitive models. An SVG cannot contain a working Roblox 3D viewport, animated avatar or runtime camera. The blank editable item template retains its preview frame/pedestal.

Screens preserve reference positions at 1366x767. Cropped panels are isolated with a small margin. Shop_CompleteExpanded, Shop_All12Items, Panel_AllGamesExpanded and CompactPanel_AllGamesExpanded expose the entire scrolling content; the expanded SVG backplates/footer positions differ only in these design exports. Normal panel files preserve the original scroll clipping.

Timers, names, stamina, votes, coin balances, rewards and XP in state examples are representative values. The level-one examples use the current 200 XP threshold; win examples use 150 coins/50 XP. Templates retain other authored sample wording. These SVGs are visual design files and do not include game behavior.

No Roblox objects, scripts, positions, sizes or capabilities were changed for this export. NativeGuiSnapshot.json is the read-only authored capture. CaptureGui.luau, ExportSVGs.py, StatePresets.json, BuildUIKit.py and rendering sources are included for rebuilding. WorldUI has its own reproducible sources and native-instance mapping. Export manifests and validation reports record coverage and file checks.
