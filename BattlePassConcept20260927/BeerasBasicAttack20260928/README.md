# Beeras basic attack integration

Prepared from the live Edit-mode Roblox Studio sources exported on 2026-09-28 to `../persistence-audit`. These three Luau files are proposed replacements for `ReplicatedStorage.CombatController`, `ReplicatedStorage.AttackTimeline`, and `ReplicatedStorage.AttackAnimator`. They have not been applied in Studio. Merge them with any later changes to those modules before applying.

Beeras's basic attack starts every 3 seconds, raises one hand, charges a purple orb for 2 seconds, and then fires a purple beam. Its 97 damage comes from Beeras's `UnitData.damage` base value; existing player unit-level stat scaling still applies. The attack marks itself released once, then adds damage once per live opposing unit intersected by the forward beam. Dead units, friendly units, units behind Beeras, and units outside the beam do not take damage. `World Destroyer` remains an ability name only; no ability effect is implemented here.

Arena formation depths are front=6, mid=13, back=21 studs. Range index 3 acquires targets within 22 studs, which would end before an aligned backline target when Beeras starts on the opposite midline. The released beam therefore continues 16 studs beyond target-acquisition range, for 38 studs total. Its horizontal hit radius is 1.25 studs plus half the target PrimaryPart's larger horizontal dimension. That reaches the same column through the three lines while excluding adjacent columns spaced up to 6 studs apart. The rendered beam follows the attacking hand along a fixed forward direction through its full reach.

This patch deliberately does not change `UnitData`, `PlayerData`, pack odds, purchase entitlement, or persistent rewards. Registering `Beeras` in `UnitData` must be paired with a default locked state: `PlayerData.unitUnlockState` otherwise treats unknown IDs as owned. The current pack definitions contain no Mythic roll probability, so a paid tier-1 unlockable Beeras still cannot appear in a pack until that rule is specified. `ReplicatedStorage.UnitModels.Beeras` is also needed for deployment and previews; the source model currently lives at `Workspace.Beeras`.

`geometry-smoke.cjs` checks the 22+16 stud reach, front/mid/back hits, side/behind/out-of-range misses, side and alive filtering, and the 2-second/3-second timing constants. It passed locally with Node. The Luau files have not yet been compiled or playtested in Studio. Before release, verify R6 hand pose and beam visuals, simultaneous multiple hits, target dying during charge, effects disabled, pause/resume, and unaffected attacks by other units. Combat and match results currently run on the client, so this patch is not server-verifiable for durable rewards.
