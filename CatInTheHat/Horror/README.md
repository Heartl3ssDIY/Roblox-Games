# Cat in the Hat — horror variant

This variant keeps the striped hat, red bow, white gloves, pale face and belly, and curved tail. It changes the expression and silhouette for a horror-game character.

- Sunken, dark eye sockets and narrow pupils.
- Lower, angular brows and a slightly tilted, forward-leaning head.
- A wide fixed grin with separate upper and lower rows of uneven teeth.
- Longer glove fingers, lower hands, and a slimmer waist.
- Darker crimson cloth and aged ivory colours.

The hat bands, bow pieces, gloves/cuffs, body, white bib, face, eyes, teeth, and tail remain separate recolourable meshes. Solid material colours are independent of the normal texture.

**CatInTheHat_Horror.blend** is the editable project. **CatInTheHat_Horror.fbx** and **CatInTheHat_Horror.glb** are import exports. **CatInTheHat_Horror_Studio.png** shows the geometry in clear lighting, while **CatInTheHat_Horror_Portrait.png** shows the expression under horror lighting. **Cat_SurfaceNormal.png** contains the surface detail.

The original base is still in the parent folder. **Before_Horror.blend** captures the live Blender state immediately before this variant was made.

This remains an **unrigged visual base**. It has not been imported into Studio, animated, or connected to a playable morph. When importing later, retain the individual meshes and check the total height is approximately eight studs including the hat.

Exact part names and colour values are in **Horror_Model_Parts.json**. The exported files are checked by reopening them in Blender; that does not replace a future Studio playtest.
